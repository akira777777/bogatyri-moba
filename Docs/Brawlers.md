# Бойцы (Brawlers)

## Общие правила баланса

- **Power Level 1** — базовые статы. Каждый уровень +5% к здоровью и урону.
- **Супер заряжается** от попаданий по врагам (указан процент за попадание).
- **Скорость передвижения:** медленная 3.8, обычная 4.2–4.5, быстрая 5.0+, очень быстрая 5.5+
