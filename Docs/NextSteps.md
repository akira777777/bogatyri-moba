# Следующие шаги по разработке

## Немедленно (сегодня)

1. **Установить Unity 2022.3 LTS** на рабочую машину.
2. Создать новый 2D проект.
3. Скопировать папки `Scripts`, `Editor`, `Docs` из этого репозитория.
4. В Unity: `Bogatyri → Generate Brawler Data` — создаст все 8 ScriptableObject'ов.
5. Создать простую тайлмап-карту (квадраты разных цветов — достаточно).
6. Назначить `BrawlerController` на префаб, добавить `Rigidbody2D`, `CircleCollider2D`.
7. Запустить сцену и проверить движение + стрельбу.

## Неделя 1: Core Loop (локально)

- [ ] Джойстик UI (можно взять бесплатный с Asset Store или написать свой).
- [ ] 3 бойца с разными способностями.
- [ ] 1 карта для Gem Grab.
- [ ] Боты (простой AI: идти к центру, стрелять в ближайшего врага).
- [ ] HP-бары, таймер, счёт.

## Неделя 2: Photon PUN 2 (онлайн)

- [ ] Импорт Photon PUN 2.
- [ ] Создать App ID на photonengine.com.
- [ ] Синхронизация позиций (`PhotonTransformView`).
- [ ] RPC для стрельбы и получения урона.
- [ ] Серверная валидация: проверка дистанции, урона, скорости.
- [ ] Комнаты на 6 человек (3v3).

## Неделя 3–4: Контент

- [ ] Добавить 5 оставшихся бойцов.
- [ ] Режим Heist + 2 карты.
- [ ] Power Level 1–5.
- [ ] Trophy Road (UI + награды).

## Неделя 5–6: Социал и полировка

- [ ] Пати (приглашение друзей).
- [ ] Глобальный чат.
- [ ] Балансировка (изменение цифр в ScriptableObject'ах).
- [ ] VFX частицы для атак и суперов.
- [ ] Анимации (пока базовые — idle, run, attack).

## Арт (параллельно)

- [ ] Концепт-арт 1 бойца (Алёша) — топ-даун вид.
- [ ] Стиль: не копировать «Мельницу», но можно использовать как референс.
- [ ] Тайлсет для карт (трава, камни, кусты).

## Тестирование

- [ ] Играть 10 матчей 1v1 локально — проверить fun factor.
- [ ] Если боевка «не цепляет» — менять скорость, урон, перезарядку (быстро через SO).
- [ ] Soft-launch: друзья играют через APK / TestFlight.
